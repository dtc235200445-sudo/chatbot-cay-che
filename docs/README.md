| Phase | Tài liệu | Nội dung |
|---|---|---|
| 0 | [00_PROJECT_SCOPE.md](00_PROJECT_SCOPE.md) | Đề tài, mục tiêu, đối tượng, phạm vi làm/không làm, rủi ro |

| 2 | [02_ARCHITECTURE.md](02_ARCHITECTURE.md) | Sơ đồ kiến trúc, luồng xử lý, pipeline RAG, mô hình dữ liệu, quyết định thiết kế, hạn chế |
| 3 | [DATABASE_SCHEMA.md](DATABASE_SCHEMA.md) | Lược đồ cơ sở dữ liệu chi tiết |
| 4 | [DATA_SOURCES.md](DATA_SOURCES.md) | Nguồn dữ liệu, giấy phép, mức bao phủ chủ đề, nguồn đã loại và nguồn chờ |
| 6 | [RAG_EVALUATION.md](RAG_EVALUATION.md), [RAG_EVAL_RESULTS.md](RAG_EVAL_RESULTS.md), [RAG_AUDIT.md](RAG_AUDIT.md) | Thiết kế RAG, số liệu đánh giá, đối chiếu với project tham khảo |

| 6–7 | [ANSWER_EVALUATION.md](ANSWER_EVALUATION.md), [ANSWER_EVAL_RESULTS.md](ANSWER_EVAL_RESULTS.md), [answer_review_sheet.md](answer_review_sheet.md) | Đánh giá chất lượng câu trả lời của LLM: cách đo, kết quả ba model, độ tin cậy của model chấm, phiếu chấm tay |
| 3–10 | [reports/](reports/) | Báo cáo hoàn thành và kiểm toán từng phase (lưu trữ) |
